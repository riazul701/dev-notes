# Carry-CPU-Monitor-In-Trolley.md

## Notes

* Must Check Trolley's Weight Capacity In KG, So That CPU And Monitor Can Be Carried Easily. Choose Double Weight Capacity Than Required.

* Buy Fiber Trolley From Good Brand, Which Is Lightweight, Strong And WaterProof. Must Be Opened Fully And Have Clearance, To Get Out CPU Easily.

* Trolley Must Have Good Quality Wheels, To Run In Rough Road Like Brick-Road.

* Place DhewTin-House-Foam Between CPU And Monitor.
  * For Safety, Separately Transport CPU (Inside Trolley) And Monitor (Inside Briefcase).
