# Commands/Usage

# [Top 50 Chrome Keyboard Shortcuts](https://clickup.com/blog/chrome-shortcuts/)

* Windows/Linux keyboard shortcut => Action

* `Ctrl + T` : Open a new tab

* `Ctrl + W` : Close current tab	

* `Ctrl + Shift + T` : Reopen closed tab

* `Ctrl + N` : Open a new window

* `Ctrl + Shift + W` : Close current window

* `Ctrl + Shift + N` : Open incognito window

* `Ctrl + Tab` : Switch to the next tab

* `Ctrl + Shift + Tab` : Switch to the previous tab

* `Ctrl + 9` : Open the last tab

* `Ctrl + Shift + PgUp/PgDn` : Move tab left/right

* `Alt + E or F` : Open the Chrome menu

* `Ctrl + H` : Open the history tab

* `Ctrl + J` : Open the downloads page

* `Ctrl + Shift + B` : Open the bookmarks tab

* `Ctrl + F` : Open the find bar (search page)

* `Ctrl + +` : Zoom in on the page

* `Ctrl  + –` : Zoom out on the page

* `Ctrl + 0` : Reset page zoom to 100%

* `Space or PgDn` : Scroll down the web page	

* `Shift + Space or PgUp` : Scroll up the page

* `Alt + ←` : Go back to the previous page

* `Alt + →` : Go forward to the next page

* `Ctrl + R` : Reload current webpage

* `Ctrl + Shift + R` : Reload current page (ignore cache)

* `Ctrl + Shift + I` : Open developer tools

* `Ctrl + Shift + J` : Open JavaScript console

* `Shift + Esc` : Open Chrome task manager

* `Alt + E, then S` : Open Chrome settings page

* `Ctrl + Shift + E` : Open the extensions page

* `Ctrl + P` : Open print dialog

* `Ctrl + D` : Bookmark current page

* `Ctrl + U` : View page source

* `Ctrl + S` : Save the current page as PDF

* `Ctrl + F` : Find a specific word, search term, or phrase

* `Ctrl + Click` : Open link in a new tab

* `Shift + Click` : Open link in a new window

* `Ctrl + Shift + Click` : Open link in an incognito window

* `Ctrl + Alt + W` : Close all tabs except the current one

* `Ctrl + M` : Mute/unmute current tab

* `F11` : Toggle full-screen mode

* `Ctrl + Shift + D` : Bookmark all open tabs

* `Ctrl + L` : Jump to address bar

* `Ctrl + Shift + B` : Toggle bookmarks bar

* `Ctrl + Shift + Delete` : Open the clear browsing data window

* `Ctrl + H` : View browsing history

* `Ctrl + O` : Open File Explorer to import/export

* `Alt + Home` : Open home page

* `Shift + Alt + T` : Focus on the next item in the toolbar

* `F1` : Open the Chrome Help Center in a new tab

* `Ctrl + Shift + O` : Toggle bookmark manager
